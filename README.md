# Student Management System

A web-based Student Management System built using Python Flask,
SQLite, HTML, CSS, and JavaScript.

## Features

- Add student records
- View student details
- Search students
- Update student records
- Delete student records
- Calculate totals, percentages, and grades
- Store records in a database

## Tech Stack

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
